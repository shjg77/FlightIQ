# ميزات النسخة الأولى (MVP Features)

## الهدف

بناء نسخة أولية من FlightIQ تقدم القيمة الأساسية للمستخدم: مساعدته على فهم رحلته والوصول إلى بوابته بسهولة، مع توفير تنبيهات ومعلومات ذكية تساعده أثناء السفر.

---

## 1. إدارة الرحلة

- [ ] إضافة الرحلة باستخدام رقم الرحلة.
- [ ] رفع بطاقة الصعود أو تذكرة السفر.
- [ ] استخراج معلومات الرحلة.
- [ ] عرض معلومات الرحلة الأساسية.
- [ ] عرض الوجهة ووقت الرحلة والبوابة.

---

## 2. تحديثات الرحلة

- [ ] عرض حالة الرحلة.
- [ ] اكتشاف تغيير البوابة.
- [ ] إرسال تنبيه عند تغيير البوابة.
- [ ] إرسال تنبيه عند اقتراب موعد الصعود.
- [ ] تحديث معلومات الرحلة.

---

## 3. الملاحة داخل المطار

- [ ] تحديد موقع المستخدم.
- [ ] عرض موقع البوابة.
- [ ] رسم المسار من موقع المستخدم إلى البوابة.
- [ ] حساب الوقت المتوقع للوصول.
- [ ] إعادة حساب المسار عند تغيير البوابة.
- [ ] إعادة توجيه المستخدم عند الخروج عن المسار.

---

## 4. الإرشاد الصوتي

- [ ] تقديم تعليمات صوتية خطوة بخطوة.
- [ ] تشغيل وإيقاف الإرشاد الصوتي.
- [ ] استخدام تعليمات قصيرة وواضحة.
- [ ] دعم التفاعل الصوتي في مراحل لاحقة.

---

## 5. Assisted Travel

- [ ] السماح لفرد العائلة بإعداد رحلة لشخص آخر.
- [ ] رفع بطاقة الصعود أو التذكرة نيابة عن المسافر.
- [ ] استخراج معلومات الرحلة تلقائيًا.
- [ ] مشاركة الرحلة مع المسافر.
- [ ] توفير واجهة مبسطة للمسافر.
- [ ] توفير زر واضح "أرشدني".
- [ ] توفير زر "أحتاج مساعدة".

---

## 6. التجربة المبسطة

- [ ] واجهة بسيطة وقليلة الخيارات.
- [ ] أزرار واضحة وكبيرة.
- [ ] تعليمات قصيرة.
- [ ] الاعتماد على الصوت والصور بالإضافة إلى النص.
- [ ] عرض خطوة واحدة في كل مرة أثناء الملاحة.

---

## 7. توقع تأخير الرحلات

- [ ] جمع بيانات الرحلات التاريخية.
- [ ] تجهيز البيانات للتدريب.
- [ ] بناء نموذج أولي لتوقع التأخير.
- [ ] عرض احتمالية التأخير للمستخدم.
- [ ] توضيح أن التوقع احتمالي وليس ضمانًا.

---

## 8. توقع الازدحام

- [ ] جمع البيانات اللازمة لتقدير الازدحام.
- [ ] تحديد العوامل المؤثرة في الازدحام.
- [ ] بناء نموذج أولي لتوقع مستوى الازدحام.
- [ ] عرض مستوى الازدحام للمستخدم بطريقة بسيطة.

---

## 9. معلومات الطقس

- [ ] عرض حالة الطقس في موقع الرحلة.
- [ ] عرض الظروف الجوية المهمة.
- [ ] ربط الظروف الجوية بتحليل التأخير في مراحل لاحقة.

---

# الميزات المؤجلة لما بعد MVP

- [ ] دعم عدد كبير من المطارات حول العالم.
- [ ] دعم لهجات سعودية متعددة.
- [ ] Family Tracking متقدم.
- [ ] التكامل المباشر مع شركات الطيران.
- [ ] تتبع الأمتعة.
- [ ] حجز الرحلات.
- [ ] المساعدة البشرية المباشرة.
- [ ] ميزات ذكاء اصطناعي متقدمة.
- [ ] توسيع الملاحة لتشمل جميع خدمات ومرافق المطار.

---

# معيار نجاح الـ MVP

يعتبر MVP ناجحًا إذا استطاع المستخدم:

1. إضافة رحلته.
2. معرفة معلومات رحلته الأساسية.
3. معرفة بوابته.
4. الوصول إلى البوابة باستخدام الملاحة.
5. الحصول على تنبيه عند تغيير البوابة.
6. الحصول على إرشادات صوتية أثناء التنقل.
7. استخدام Assisted Travel عند الحاجة.
8. الحصول على توقع أولي للتأخير والازدحام.
